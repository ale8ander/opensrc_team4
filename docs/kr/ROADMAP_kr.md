# 프로젝트 로드맵

**이 문서는 본 프로젝트의 예정된 기능과 개선 사항을 설명합니다.
로드맵은 커뮤니티 피드백 및 프로젝트 요구사항에 따라 변경될 수 있습니다.**

---

## 완료된 항목

* 기본 손 제스처 인식 (정적 제스처)
* 명령 키 매핑:

  * ✌️ Victory → 탭 닫기
  * ✊ Fist → 새로 고침
  * ✋ Open Hand → 이전 페이지로 이동
* 기본 OpenCV 연동
* 기본 MediaPipe 연동
* 초기 프로젝트 문서화 (README, CONTRIBUTING, INSTALL)

---

## 예정된 기능

* 제스처 인식 정확도 향상
* 프레임 처리 속도 최적화
* 코드 구조 리팩터링 및 유지보수성 개선
* UI/UX 개선
* 추가 제스처 지원
* 동적 제스처 인식 (움직임 기반 제스처)
* 다중 손 인식 (왼손 / 오른손 구분)
* 사용자 정의 명령 키 매핑 (사용자 설정 핫키)
* 성능 분석 및 최적화
