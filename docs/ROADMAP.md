# Project Roadmap

**This document outlines the planned features and improvements for this project.  
The roadmap is subject to change based on community feedback and project needs.**

## Completed

- Basic hand gesture recognition (static gestures)
- Command mapping for:
  - ✌️ Victory → Close Tab
  - ✊ Fist → Refresh
  - ✋ Open Hand → Go Back
- Basic OpenCV integration
- Basic MediaPipe integration
- Initial project documentation (README, CONTRIBUTING, INSTALL)

## Planned Features

- Improve gesture recognition accuracy
- Optimize frame processing speed
- Refactor code structure for better maintainability
- Enhance UI/UX
- Support more gestures
- Dynamic gesture recognition (movement-based gestures)
- Multi-hand recognition (left/right hand differentiation)
- Customizable command mapping (user-defined hotkeys)
- Performance profiling and optimization
